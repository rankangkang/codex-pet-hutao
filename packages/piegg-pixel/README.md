# 皮蛋 · 像素版（预览版）

根据皮蛋的照片制作的像素风 PetDesk 桌宠。动画图为透明的 Codex v2 格式，包含九组动作和十六个注视方向。

在 PetDesk 的「宠物库」选择「导入桌宠」，选中本目录，再选择「导入并使用」。写实版和像素版可同时保存在宠物库中；均在本地运行，不需要 Agent。

单击皮蛋可以看抬爪，双击可以看跳跃。「桌面设置」→「基础动作」中的「专注」对应短暂舔鼻子的动作。

`spritesheet.png` 和 `pet.json` 是导入所需文件；`preview.png` 是待机预览。`source/` 保存基准图、动作条、提示词及重新组装图集的工具。
